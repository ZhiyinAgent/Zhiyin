All three cases run in the installed app on 2026-09-10. Recorded from the
application's own saved history, which holds the verbatim request, every action,
and the provider evidence for each model response.

Model: `z-ai/glm-5.3-flash`. Serving upstream: Z.AI, for every response in all
three runs. Fixture version 1 for each case. Every model response terminated on
an explicit finish reason and was recorded complete; none was truncated or
interrupted.

Cost is not attributable per run. The provider reports usage per account and

## research-build-check

Verbatim request typed. 22 model rounds, 23 actions, 19 minutes 45 seconds from
first request to last.

Four Tavily searches and one extract; loaded the frontend-design skill; asked the
system for today's date; wrote `largest-hydroelectric.html`; previewed it,
resized to desktop and phone, captured and looked at both.

Result: **pass.** Three Gorges 22,500 MW, Baihetan 16,000 MW, Itaipu 14,000 MW —
matching the answers recorded before the run. Each figure cross-checked against a
second independent source, and it said which sources it could not pin to a
non-encyclopedia origin. It looked at what it built at 1440x900 and 390x844,
found two real layout defects at phone width — the table caption collapsing to
one word per line, and mixed text splitting inside cells — fixed them, and
re-checked desktop afterwards.

One action failed and recovered: it looked for a captured image at a path with
the user name missing, was refused, found the real path with a shell command,
and carried on. The refusal reached the record rather than being hidden.

## data-regional-sales

Verbatim request typed. 5 model rounds, 4 actions, 2 minutes 10 seconds.

Result: **pass.** Total 24,448.25 and all four regional figures exact against

with no units, Iqbal with no unit price. The outlier surfaced with the

## What these runs do not establish

They are the cases the assistant that built the product also wrote, so they show
it can do the cases it was shown. That limit is recorded in the evaluation
README and is not resolved by these results.

Denied permission, interruption mid-work, restart, unavailable provider, failed
save, and externally changed inputs were not exercised in any of the three. The
mechanisms behind each are covered by regressions; being covered by a regression
is not the same as being exercised in a case, and the protocol asks for both
before the broad alpha milestone.
