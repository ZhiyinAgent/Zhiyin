# Review project-suggested capabilities before activation

## What and why

Import suggested connections or instructions without treating folder access as
authority to activate them.

## Done when

Opening a folder never contacts suggested endpoints or loads project instructions
automatically. Project-source trust is defined before project imports are enabled -
absorbed from `skills-source-precedence`, whose bundled-versus-user precedence is
done and whose only live remainder was this. Import previews show origin, exact destination, and requested access.
Changed definitions require renewed review. Credentials are handled by the connection
owner, independently of import.
